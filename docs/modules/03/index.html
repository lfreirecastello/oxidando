01 · Domain shape

A struct gives related fields one named type

Unlike a loose map or object literal, a struct tells the compiler exactly which fields and types form a valid value.

Rustincident.rs
struct Incident {
    id: u32,
    service: String,
    open: bool,
}

let incident = Incident {
    id: 42,
    service: String::from("checkout"),
    open: true,
};
Python bridge

Think of a typed dataclass. Rust requires every field to be initialized and applies ownership rules to each value stored inside.

Java bridge

Think of a compact data class or record. Rust keeps the stored fields in the struct and places methods in separate impl blocks.

JavaScript bridge

It resembles an object with an intended fixed shape, but missing or incorrectly typed properties are compile-time errors rather than conventions.

02 · Inherent behavior

impl attaches functions to your type

Self means the current type. A receiver of &self reads, &mut self mutates through an exclusive borrow, and self consumes the value.

Rustincident_impl.rs
impl Incident {
    fn new(id: u32, service: &str) -> Self {
        Self { id, service: service.to_owned(), open: true }
    }

    fn close(&mut self) {
        self.open = false;
    }
}
&selfBorrow to read

The caller retains ownership.

&mut selfBorrow to change

Exclusive access lasts for the call.

selfConsume the value

The method receives ownership.

03 · Shared contracts

A trait names a capability

The trait declares what conforming types can do. The implementation connects that contract to a concrete type; it does not inherit stored fields.

Rustsummary.rs
trait Summary {
    fn summary(&self) -> String;
}

impl Summary for Incident {
    fn summary(&self) -> String {
        format!("INC-{}: {}", self.id, self.service)
    }
}
Python bridge

A trait resembles a Protocol or abstract base class, but conformance is compiled into the program rather than discovered through runtime duck typing.

Java bridge

A trait is close to an interface with default methods. Rust favors composition and does not use class inheritance for shared state.

JavaScript bridge

JavaScript often relies on “has this method” conventions. Rust gives that convention a name and checks every implementation and caller.

#[derive(Debug, Clone, PartialEq)] asks the compiler to generate standard trait implementations. Derive mechanical behavior; write an explicit implementation when domain meaning matters.

04 · Honest reuse

Generics remove duplication; bounds declare needs

T stands for a concrete type chosen by the caller. T: Summary says that choice must implement Summary, so the function body can safely call its method.

Rustpublish.rs
fn publish<T: Summary>(item: &T) {
    println!("{}", item.summary());
}

// Equivalent when several bounds need room:
fn log<T>(item: &T)
where
    T: Summary,
{
    println!("{}", item.summary());
}
Word you just met · trait bound

A compile-time requirement on a generic type. It documents and enforces the capabilities the implementation uses.

Intermediate depth · dispatch

Generic trait-bounded calls normally use static dispatch: the compiler specializes code for each concrete type. &dyn Summary chooses runtime dynamic dispatch instead.

Advanced depth · trade-off

Monomorphization removes virtual-call overhead and enables optimization, while potentially increasing code size. Trait objects trade some runtime indirection for heterogeneous storage and smaller call-site code.
